### Selected projects

**[Online Trivia Quiz](https://github.com/dmarenic/online-trivia-quiz)** · [Live demo](https://online-trivia-quiz.vercel.app/) · my final thesis<br>
Real-time multiplayer quiz where players join a private room with a code and compete on a live leaderboard. The game logic runs on the server over Socket.IO: it scores answers by accuracy and speed, and it never sends the correct answer before a player has answered.<br>
TypeScript · Next.js · NestJS · Socket.IO · PostgreSQL · Prisma · Gemini API · GitHub Actions

**[RateMyMeal](https://github.com/dmarenic/ratemymeal)** · team project<br>
Django platform where people post meals with photos and ratings, comment on them and follow each other. It has four user roles (user, food critic, restaurant owner and admin), each with its own permissions. We were a team of two, and I built most of the frontend and backend.<br>
Python · Django · SQLite · Bootstrap

**[Blue Pulse](https://github.com/dmarenic/blue-pulse)** · Android app<br>
Android app for GNK Dinamo Zagreb fans with matches, the squad, the league table, player-of-the-month voting and a shared photo gallery. Match and player data are saved locally with Room, so those screens also work offline.<br>
Kotlin · Jetpack Compose · Firebase · Room · Retrofit
